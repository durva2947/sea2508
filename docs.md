# Project title: The Effect of Remote Learning on Undergraduate Student Engagement
Project type: Mixed-methods academic research study
Project duration: January 2026
Project owner: Department of Education
Research team: Principal investigator, student researchers, data analyst, and academic supervisor

## Purpose of the documentation
The documentation serves four connected purposes:
Define the research problem It explains whether remote learning affects attendance, participation, motivation, and academic performance.
Guide the research team It records objectives, responsibilities, deadlines, methods, and approval requirements.
Support transparency and reproducibility Another researcher should be able to understand how participants were selected, how data was collected, and how conclusions were reached.
Preserve project knowledge The files provide a record of decisions, data, analysis, limitations, and lessons learned.
Keeping the documents in one organized repository gives the team a shared source of information and reduces confusion caused by outdated or scattered files.
